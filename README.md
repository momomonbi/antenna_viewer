# antenna_viewer — 閲覧専用ビューア

このリポジトリの `index.html` は **自動生成物です。直接編集しないでください。**

メイン（`antenna_main` の `index.html`）から、
`antenna_main/開発ツール/ビューア生成.ps1` が作り出しています。

## 直したいときは

| 直したい内容 | 直す場所 |
| --- | --- |
| 積算・図面・地図・印刷など本体の機能 | `antenna_main/index.html` |
| 閲覧専用の「隠す・止める」まわり | `antenna_main/開発ツール/viewer-block.html` |

どちらを直した場合も、そのあとに生成スクリプトを実行して
ここの `index.html` を作り直します。

```
powershell -ExecutionPolicy Bypass -File "J:\Dropbox\仕事\アンテナ取付工事\開発ツール\ビューア生成.ps1"
```

くわしくは `antenna_main/開発ツール/README.md` を見てください。

## このビューアの性格

- 表示・計算・印刷はメインとまったく同じです（本体コードは書き換えていません）。
- 保存・同期・世代バックアップ・`.bak` 出力などの**書き込む処理は止めてあります**。
  共有フォルダのデータが書き換わることはありません。
- 入力・編集の UI は隠してあります。地図は「クリック＝選択／ドラッグ＝パン」に固定です。
- 追加されている部分には `==VIEWER-MODE … ==` の目印が入っています。

## 物件データについて

このリポジトリに置くのは**ビューア本体（データなし）だけ**にしてください。
個人情報を含む物件 JSON を公開リポジトリに置くと誰でも見られます。
